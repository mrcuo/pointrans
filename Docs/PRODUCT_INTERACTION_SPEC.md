# Pointrans 产品交互与逻辑规格

状态：已实现的 2.0 产品契约
日期：2026-08-31

## 1. 产品定义

Pointrans 是常驻 macOS 菜单栏的中英光标翻译工具。唯一触发动作是：按住左 Option，把光标停在英文或简体中文词语上。

以下原则不可由设置或降级逻辑改变：

- 左 Option 固定，不提供触发键设置。
- 自动识别英文与中文，不提供翻译方向设置。
- 辅助功能和屏幕录制均为正式工作状态的必需权限。
- 中英两个方向的 Apple 翻译语言能力自动准备，首次引导未准备完成时不能继续。
- 基础翻译固定按设备端 AI（最多等待 1 秒）、Apple 翻译、本地词典的顺序决策。
- 语境解释只能由用户点击触发；设备端优先，只有已获同意时才能自动回退 Worker。
- 不提供 AI 开关、模型、Provider、API Key 或语言包人工配置。
- 首次引导必须获得目标词的真实翻译和真实语境结果，不能用模拟结果跳过。

## 2. 应用外壳

### 2.1 唯一菜单栏状态项

- 进程启动时立即创建一个 `NSStatusItem`，同步配置图标、tooltip 和 target/action。
- 不使用 `terminationOnRemoval`，菜单栏图标被系统遮挡时进程仍继续运行。
- 状态项创建失败属于致命启动错误；应用显示可理解错误并退出，不留下不可见进程。
- 左键切换独立控制中心；右键显示“打开控制中心、暂停/继续翻译、退出 Pointrans”。
- 菜单栏图标不是窗口唯一入口。用户再次打开正在运行的 App 时，始终置前独立控制中心。

### 2.2 窗口职责

| 界面 | 生命周期 | 唯一职责 |
| --- | --- | --- |
| 首次引导窗口 | `onboardingVersion` 未完成 | 权限、语言能力、强制真实体验与按需隐私确认 |
| 控制中心 | 菜单栏左键或重开 App | 状态、暂停、悬停延迟、能力修复、云端授权、退出 |
| Preview | 真实基础翻译完成或超过 200ms 仍在读取 | 瞬时展示与进入 Pinned |
| Pinned | 用户点击卡片或语境解释 | 选择、滚动、朗读、复制、语境解释、拖动和关闭 |

完成首次引导后的冷启动只有菜单栏状态项。启动后 700ms 仍没有有效菜单栏锚点时，自动显示居中的控制中心作为恢复入口。

### 2.3 退出

退出会停止 event tap、dwell、AX/OCR、翻译、设备 AI、Worker 请求和窗口任务，然后结束唯一应用进程。退出后 Finder 应能立即删除 App。

## 3. 首次引导

首次引导版本为 `3`。旧版 `didCompleteOnboarding`、v1 或 v2 不会绕过新流程；v2 停留在独立隐私页的状态会迁移到一体化真实体验。Bundle ID、UserDefaults 域、Keychain 和 TCC 身份保持不变。

流程共五步，当前阶段实时写入 UserDefaults，系统要求重开时从原阶段继续：

每一阶段都保留显式“退出 Pointrans”，即使菜单栏状态项被系统遮挡，用户也不会被困在不可卸载的后台进程中。

1. **认识 Pointrans**：只说明固定左 Option、悬停和自动识别。用户必须真实按下一次左 Option；页面中的 Left Option 胶囊立即点亮反馈，短暂停留后自动进入辅助功能步骤。右 Option 或其他按键不响应，本步骤没有可跳过的“继续”按钮。
2. **辅助功能**：必需；系统实际授权前不能继续。
3. **屏幕录制**：必需；说明仅在本机处理光标附近区域，截图不保存、不上传。系统已接受但当前进程尚不能使用时进入 `restartRequired`，保存阶段并要求用户退出后重开。
4. **准备语言能力**：依次验证/准备英中和中英 Apple 翻译；只显示进度、明确失败和重试。
5. **强制真实体验**：页面直接显示完整示例句，`breakthrough` 作为独立蓝色目标控件，不依赖 AX/OCR 重新识别自家界面。页面根据鼠标、左 Option、读取、翻译、语境和完成状态逐步给出唯一下一动作；真实翻译和真实语境结果都直接留在页面内，全部成功后自动完成，不再要求理解 Preview/Pinned 或点击额外完成按钮。

引导不再提前展示独立“云端回退”页面。用户点击语境解释后先在设备端运行；只有设备端出现可恢复的不可用错误，才在结果原位用自然语言说明本次在线解释会发送示例词和示例句、不会发送截图或应用信息，并让用户选择。拒绝在线解释且设备端不可用、离线、额度耗尽、权限撤销或语言能力失败都会保留在当前步骤并显示对应恢复动作，不存在“跳过”。

## 4. 应用状态

统一 `AppReadiness`：

```text
launching
onboarding
ready
paused
needsAccessibility
needsScreenCapture
preparingLanguagePack
recoveringListener
listenerFailed
fatalStartupError
```

规则：

- 任一必需权限缺失时不能进入 `ready`，监听器必须停止。
- 暂停会停止监听并取消当前会话，但保留菜单栏状态项。
- event tap 使用 0.5、1、2、4、8 秒的有限恢复序列；耗尽后进入 `listenerFailed`。
- 权限只在首次引导、控制中心、权限请求完成和应用重新激活时刷新，不做后台轮询。
- 运行期重新激活时重新验证语言能力；发现语言包被移除则自动准备。准备期间设备端 AI 与词典仍可工作。

## 5. 光标取词状态机

```text
idle
→ leftOptionDown
→ dwelling
→ extracting
→ detectingLanguage
→ resolvingTranslation
→ preview
→ pinned
→ closed
```

- 只有 Carbon 左 Option 键码 `kVK_Option` 被接受；右 Option、Command、Control 和 Shift 均不触发。
- 按下时固定锚点。快速移动或超出半径会取消旧 dwell，并在新位置重新计时。
- 提取完成前释放左 Option，立即取消任务；忽略供应方取消的迟到结果也不能获得会话所有权。
- Pinned 存在时拒绝新取词。
- AX 优先；AX 不支持或未命中文字后才使用 ScreenCaptureKit + Vision OCR。
- OCR 每次只捕获光标附近区域，识别语言固定为英文和简体中文。
- 标点、空白和不支持文字静默结束。

每次会话包含不可变 UUID、锚点、display ID、目标词、最多 600 UTF-16 上下文、精确目标范围、自动方向和创建时间。

## 6. 自动语言与方向

- 光标所在词元为拉丁字母：英译中。
- 光标所在词元为汉字：中译英。
- 混合句子按光标实际命中的词元决定，不按整句多数文字决定。
- 不支持词元不创建翻译请求。

## 7. 基础翻译路由

三个任务可以并行预取，但展示决策严格固定：

1. 设备端 Foundation Models AI 获得最多 1 秒优先窗口，使用目标词和有限上下文，只返回简短译词。
2. AI 成功立即使用 `deviceAI`；失败则立即降级。
3. AI 到达期限仍未成功，立即取消并永久关闭该会话的 AI 展示资格。
4. Apple Translation 成功则使用 `appleTranslation`，并可附带词典音标/拼音。
5. Apple Translation 失败则使用 `dictionary`。
6. 三路全部失败时显示短暂明确错误，不展示空白面板。

超时竞速使用一次性 continuation gate，不等待忽略取消的迟到 AI 任务，因此“1 秒”是展示上限而不是建议值。

## 8. Preview 与 Pinned

### Preview

- 显示原词、主翻译、音标/拼音、来源、朗读和语境解释入口。
- 200ms 内没有结果时显示轻量“正在读取”。
- 释放左 Option 后通过安全走廊短暂保留。
- 移出安全走廊、外部点击、Escape、新会话或超时关闭。
- 点击卡片或语境解释先转换为 Pinned。

### Pinned

- 可成为 key window，支持文本选择、滚动、朗读和复制。
- Command-C 在有文本选择时复制选择；无选择时复制完整结果。
- Escape 或关闭按钮关闭。
- 可拖动，但会钳制在取词所在显示器的可见区域内。
- 退出或重启不恢复旧结果。

## 9. 语境解释

- 只有用户点击才创建语境任务。
- 设备端 Foundation Models 优先。
- 未决定在线授权时先只运行设备端；只有设备端发生可恢复的不可用错误，Pinned 或引导页才原位请求一次在线解释授权，不在首次启动中预先询问技术路由。
- 仅 `.unavailable` 和 `.transient` 可在用户已同意时回退 Worker。
- 无效输入、安全拒绝和取消不得回退云端。
- 云端结果显示来源与剩余额度；额度耗尽显示重置时间。
- 断网、Worker 协议不兼容和额度耗尽必须保持为三个不同状态，不得统一显示成“检查网络”；它们不删除基础翻译，也不循环请求。设备端重试不得因既有在线授权再次自动进入 Worker。
- 关闭结果、暂停、开始新会话或撤销云端同意都会立即取消正在运行的语境任务。

## 10. 云端隐私契约

Worker 只服务用户点击后的语境解释，不参与自动基础翻译。

- `/v1/installations` 接受且只接受空 JSON 对象，由 Worker 生成随机匿名额度身份并返回签名令牌；客户端既有 Keychain installation UUID 被保留但不再上传。
- `/v1/context` 只接受请求 UUID、目标词、有限上下文、UTF-16 目标范围和中英方向。
- 客户端不编码截图、应用名称、Bundle 信息、设备型号、硬件 ID 或基础词典提示。
- Worker 日志只包含请求 ID、路由、耗时、状态和剩余额度，不记录词语、上下文、结果或匿名额度身份。
- 每个匿名身份每天 30 次；失败的上游请求退还额度，断网和超时不循环调用。

## 11. 控制中心

控制中心只显示：

- 当前运行状态和暂停/继续主开关。
- 固定说明“按住左 Option 并悬停”，以及自动识别提示。
- 0.15–1.00 秒悬停延迟。
- 辅助功能、屏幕录制、内置语言能力状态和恢复操作。
- 在线语境解释状态；已允许时提供关闭。未决定表示只有实际需要时才询问。
- 版本与退出。

不存在触发键、方向、AI 开关、语言包选择、模型、Provider 或 API Key 控件。

## 12. 持久化

保留：

- `translationEnabled`
- `hoverDelay`
- `cloudContextConsent`
- `onboardingVersion` 与 `onboardingStage`
- 既有匿名 Keychain installation UUID/token

删除旧键：

- `modifierKey`
- `translationMode`
- `aiEnabled`
- 旧 Provider、模型、Endpoint 和 API Key

不持久化系统权限结果、窗口、当前结果、监听状态或任务。

## 13. 交付约束

- DMG 只有 `Pointrans.app` 和 Applications 软链接。
- 构建 App 仅存在于 `build/*.noindex`，`dist` 只保留版本化 DMG。
- 构建、测试和打包不安装、不启动、不终止、不替换 `/Applications/Pointrans.app`。
- 构建和交付验证结束时扫描并注销整个仓库 `build` 树中的临时 App，同时拒绝任何可索引的仓库 App，避免 Launchpad/Spotlight 重复项。
- 安装、卸载、系统授权和真实桌面验收由用户操作。
